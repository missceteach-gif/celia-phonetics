# Celia · Fonética
Práctica A: CAT /æ/, CAR /ɑː/ y CUP /ʌ/. Ejercicios de la ficha, audios, palabras y frases sincronizadas, corrección y repaso.

Este repositorio contiene únicamente la práctica de pronunciación. No contiene exámenes, resultados, datos de alumnado ni credenciales. El proyecto general se mantiene privado.

## Desarrollo
Node 22 o superior. `npm install` y `npm run build`. Los audios se restauran desde audio-a.tar.gz. El directorio dist se publica en GitHub Pages con la ruta base /celia-phonetics/.

## Estado
A es el primer bloque. Los demás sonidos están pendientes de incorporación y revisión. No se declara completada la colección.
